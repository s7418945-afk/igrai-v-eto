# NEON DISTRICT

Небольшая оригинальная 2D игра с видом сверху на стандартном Python `tkinter`.
Дополнительные библиотеки и игровые ассеты не нужны.

## Запуск

Нужен Python 3.10 или новее:

```bash
python3 main.py
```

## Управление

- `WASD` (английская или русская раскладка) - движение или управление машиной; `Shift` - ускоренный шаг.
- Мышь - прицел и стрельба в выбранном направлении.
- `E` - сесть в машину, выйти или войти в магазин; `Esc` - закрыть меню или выйти из машины.
- ЛКМ или `Space` - импульсный бластер по тренировочным мишеням; `R` - перезарядка.
- В оружейном магазине: `1` - купить патроны, `2` - улучшить бластер.
- В автосервисе: `1` - обслуживание машины.

Город, машина, персонаж и объекты нарисованы фигурами Tkinter без внешних
ассетов. Попавшие тренировочные мишени возвращаются через несколько секунд.
